## 🌐 Como Publicar na Internet Gratuitamente

Você pode colocar este site no ar em menos de 2 minutos usando qualquer uma das plataformas gratuitas abaixo:

### 1. Vercel (Recomendado)
1. Crie uma conta gratuita em [vercel.com](https://vercel.com).
2. Arraste a pasta `samuel-lenicio-portfolio` para a tela do Vercel ou conecte ao seu repositório no GitHub.
3. Seu site estará online com HTTPS gratuito (ex.: `samuel-lenicio.vercel.app` ou seu domínio próprio).

### 2. Netlify
1. Crie uma conta em [netlify.com](https://netlify.com).
2. Vá em **Sites > Add new site > Deploy manually**.
3. Arraste a pasta inteira para o navegador. Pronto!

### 3. GitHub Pages
1. Crie um repositório no seu GitHub chamado `samuel-lenicio-portfolio` ou `samuel.github.io`.
2. Envie os arquivos `index.html`, `style.css`, `script.js` e `package.json`.
3. Em **Settings > Pages**, selecione a branch `main` e salve.
